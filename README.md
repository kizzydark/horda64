# Horda 64

Bullet heaven 3D no navegador: você é o bicho, as magias saem sozinhas e a horda não acaba.
3 fases por partida (ache o portal, derrote o chefe e fuja antes do Enxame Final), 6 estilos gráficos, co-op local e online para até 4 jogadores.

**Jogar:** https://kizzydark.github.io/horda64/

- **Sozinho:** PRESS START → Jogar → Solo.
- **Com amigos pela internet:** Jogar → Online → Criar sala → 🔗 Copiar convite e mande o link. Quem abrir entra direto na sala. Também dá para digitar o código de 5 letras.
- **No mesmo PC:** Jogar → Co-op local (dois teclados e controles).

Controles: WASD/setas ou controle para andar • Esc/Start pausa • M mudo • 1–4 escolhem cartas (no online, 1–4 também é o chat rápido).

O progresso fica salvo no navegador de cada um. Jogo de uso pessoal, com criaturas, mapas e textos originais.
